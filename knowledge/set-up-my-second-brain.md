# Set up my second brain

## Purpose
What setting up this second brain involves, and what "set up" means. The commitment itself, with its next action, is `set-up-second-brain` in the commitment list.

## Useful information
- Done when: the inbox, commitment list and notes are in daily use for two weeks, and one weekly review has run.
- Starting point: the example notes, which can be deleted once your own notes replace them.
- Agent setup: the rules file and skills are copied into the agent's folders, and the agent can search the notes.
- First review with a colleague: see [[2026-11-10-second-brain-kickoff]].

## Rationale or verification
A project note holds what the project needs to know. Its next action stays in the commitment list, so it reaches the daily brief.
